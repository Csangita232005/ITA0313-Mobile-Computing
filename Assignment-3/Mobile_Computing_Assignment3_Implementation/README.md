## Output

`results/experiment_results.csv` contains measured simulator output for:
- 8, 12 and 16 mobile nodes
- low, medium and high mobility
- DSDV and AODV
- five independent random seeds per setting by default

Metrics:
- Packet Delivery Ratio (PDR) = delivered packets / sent packets × 100
- Average delay = total delay of delivered packets / delivered packets
- Routing control messages = modelled protocol-control transmissions
- Handoffs and Mobile IP registrations
- Tunnel bytes = 20 bytes per delivered packet forwarded through the modelled Mobile IP tunnel

## Important modelling assumptions

This is a **simplified educational simulator**, not a standards-compliant implementation of RFC Mobile IPv4, DSDV or AODV, and not a packet-level radio simulator. It uses a geometric graph and simplified control-message accounting:
- Nodes move using a bounded random walk in a 100 × 100 area.
- A wireless link exists when two nodes are within 32 distance units.
- Each wireless hop contributes 2 ms.
- AODV route discovery adds 12 ms on a cache miss.
- DSDV refreshes its route table every three simulation rounds.
- AODV route cache lifetime is three rounds.
- A Mobile IP tunnel adds 5 ms and 20 bytes of outer-header overhead for a destination outside its home zone.
- A missing or stale route causes packet loss.

These values are simulation parameters for comparison, not measured real-world network performance. Change them only when documenting the changed experiment.
